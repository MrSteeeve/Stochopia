# P2-M1 连续冲击度量、复合状态与多副本方差验证

## 实验定位与固定配置

本轮重放同一批已经开启的 P1-M5 交易日，是新度量和回放协议的回顾性验证，不是新的留出测试，不重新选择 P1 最终模型，不得据此回写 P1 主终点。固定特锐德 300001.SZ、四份封存源码、训练种子 103/137/211 和已有 CPU 权重。36 训练日仅用于标定/张量准备；20 日、每天两个窗口；重抽单位始终是交易日。每个 K 使用相同的随机数种子 9127 和 2,000 次共享日重抽。零外部模型 API 调用、零新行情下载。P1 默认旧协议未改写；P2 使用显式 p2-m1 标识。

处理代码：Stochopia `f5959ebbc7f98f1b8411ef542e94c3168a92e1b2`、OpenHyra `44a908588c6af2ed9314112fac0408673657d92f`。

输入与状态契约核查：模型在编码前直接收到 `book_ticks[..., 2, 10]` 和 `book_shares[..., 2, 10]`，完整保留十档买卖报价与数量，不在框架端压为单一深度。历史前步事件的四个离散 token（等待时间、动作/方向、档位、数量）和自身动作标记同样完整传入；但原 P1 时间/数量分桶和价格截断本身是离散化，不声称原始连续事件字段逐值无损。四个固定输出词表及 NLL 归约不变。状态树支持矩阵与嵌套 tuple/dict，按单样本实标量总数计费，P2 上限 512，P1 默认 128；B=1/B=5 的前缀因果性和逐步/整序列等价保持 atol=1e-5。合成纯无状态模型的失忆差小于 1e-6，折叠批算与逐事件 state=None 对照测试通过。

## 主要结果

- **连续指标验收通过。** 四模型 K=1 与 M0/M3 的 K=4/8 共 6 个配对报告（含基线自对照），三个连续指标的点估计与 95% 区间均为 18/18 有限，独立交易日簇均为 20，每项均有 2,000/2,000 有效重抽。两模型在 K=8 的有效可见报价率均约 99.88%，并未将缺失报价填零。相对理论曲线的误差与原条件分数仍是不同研究读数。
- **失忆读数能显示不同的记忆依赖。** M1 的 reset gap 0.3310，约为 M0 0.6432 的 51.5%；M2 的 gap 0.6852，高于 M0，约为 M1 的 2.07 倍。M3 的 gap 为 0.6739。M1 的正常 NLL 反而比 M0 高 0.00903；更低的 gap 并不自动等于更好的模型。它说明读出层对给定历史记忆的依赖较小，而非形式证明读出门控的因果效果。
- **增加随机副本可以压缩本次配对估计的模拟方差。** M3−M0 的曲线 MAE 区间宽度 1.7327→0.6695→0.4803 tick（K=4 收窄 61.4%、K=8 收窄 72.3%）。所有三个区间仍跨零，符号也并不稳定，不能据此宣称 M3 提升了冲击生成质量。
- **严格条件总分仍有自己的识别边界。** 共同 C2 通过占比从 50.3% 到 80.5% 再到 90.25%，但完整严格支持的共同交易日数分别仅 13/7/6。K=1 的有限联合重抽数不足 1,800，K=4/8 的严格共同交易日数低于 10；故严格配对总分的三个 95% 区间都保留为不可判定。条件经验分布宽度可以报告，不能替代正式推断。
- **吞吐量提升而非总时间下降。** 同一双 worker 调度下，单模型/训练种子/窗口/副本的均摊墙钟从 754.13 ms 降为 311.79 ms（K=4）和 364.21 ms（K=8）；两模型组墙钟从 90.79 s 增至 151.25 s 和 356.77 s。K=4 在本次 CPU 上的单位吞吐量最高；单次序贯测量不构成硬件普适性能保证。

P2-K=1 使用新随机流地址化协议，而旧默认 P1/K=1 保留原采样实现。虽然 P2 四模型完整面板均为 IDENTIFIED_POWERLAW、原 P1 留出种子 C2 不可识别，不能将其差异全部归因于度量改进。

源码对照：M1 保留 GRU 递推不变，令读出 $c_t=g_t h_t+(1-g_t)x_t$，$g_t=\sigma(W[\mathrm{spread}_t,\mathrm{imbalance}_t]+b)$，因此改变历史信息在读出中的权重。M2 将 $|\mathrm{spread}|-|\mathrm{imbalance}|$ 追加至原始特征后再投影成 $x_t$，实际门值是 $g_t=\sigma(x_{t,-1})$（投影后最后一个坐标，而不是直接用原始门输入），$h_t=g_t\,\mathrm{GRU}(x_t,h_{t-1})+(1-g_t)h_{t-1}$，并将混合后的状态反馈到下一步。M3 在输入投影加入 $0.5\tanh(U[spread,imbalance,is\_own]+d)$ 的有界残差，随后整体 tanh；循环结构与四头保持不变。每个模型独立训练，因此这里是不同架构的后验消融读数，不是将 M1/M2 的门互换而其他权重固定的实验。

## 证据边界

保留原冻结证据与标签不变；P2 只对已有测试数据做回顾性工程验证。方差收窄与速度提升由表中实际测量决定，不假定 K 越大区间必然越窄。理论参考曲线是模型无关基准而非真实外生母单个体反事实。

兼容性：冻结的 M5 72 个、V2 40 个可执行候选全部通过新的 B=1/B=5 科学契约；真实 000001.SZ 一日两个窗口的旧默认 p1/K=1 路径复现 M0a 数值哈希 `9652af47189e3885833fa8f4b2fa28d0ad3386167a8a340d52aafa124519440d`。

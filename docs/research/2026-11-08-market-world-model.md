# 市场世界模型：逐期前推预测研究协议

日期：2026-11-08。状态：已实现，离线验证通过，尚未用真实模型跑过。
协议：`stochopia.market-world-model-forecast.v1`。

这条研究线与 Benchmark v3 分离，不改动 v3 的定价、结算、约束或指标，产物也不进入 v3 聚合。

## 定位

Stochopia 在这条线里承担三件事：
- 提供**外部环境**：真实日频 P/Q 面板；
- 提供**因果查询**：给定起点，只交出截至该日的历史前缀；
- 提供**可信评分**：CRPS skill，并用 StructurerDSL 的 payoff 探针衡量与决策相关的预测质量。

OpenHyra 承担循环本身：基座模型通过 API 修订世界模型程序，沙箱执行，记录经验。任务说明见 OpenHyra
`tasks/stochopia_world_model/TASK.md`。

## 模块

| 文件 | 内容 |
|---|---|
| `stochopia/research/market_panel.py` | 从本地 Tushare / CFFEX 缓存构建日频面板，写到 `data/derived/world_model/panel.npz` 与 `panel.json`（来源、单位、覆盖、拒绝计数）。每个字段只用当日或更早的输入。 |
| `stochopia/research/forecast_protocol.py` | 起点与划分、历史前缀、查询、输出校验、参考模型、目标（含 DSL 探针）、CRPS、skill 聚合、block bootstrap 下界、切片与校准。 |

## 面板（2026-11-08 构建）

| 字段 | 来源 | 覆盖 |
|---|---|---|
| `close` CSI500 / CSI1000 | tushare index_daily | 2015-01-05 – 2025-12-31，2674 个交易日 |
| `rate_3m` | SHIBOR 八节点曲线，滞后 ≤ 5 天 | 全部 2674 天 |
| `carry` CSI500（IC） | 当日 IC 结算价，91 天隐含 carry | 2015-04-16 起，2606 天 |
| `carry` CSI1000（IM） | 当日 IM 结算价 | 2022-07-22 起，837 天 |
| `iv_1m` CSI1000 | 当日 MO 结算链，30 天 ATM 总方差插值 | 2022-07-22 起，837 天 |

carry 与正式月频构建器有一处不同：正式构建器拒绝 |carry| > 0.2，这里不拒绝，只把 |carry| ≥ 1 视为坏值。
原因是 2015–2016 年 IC 的深度贴水是真实报价，预测任务不能把它截掉。采用这一口径后，CSI500 carry
从 2247 天增加到 2606 天。

## 评分要点

- 输入是固定长度尾部窗口：收益与利率 504 天，Q 报价 126 天。长度不泄露起点位置。
- 视野 21 个交易日，256 条联合样本路径。
- 目标共 19 个：
  - 两个指数各有对数收益、已实现波动、6 个 DSL 探针；
  - 3 个 Q 报价。
- 二值探针的 CRPS 等于 Brier 分数（有测试覆盖）。
- dev 起点 ≤ 2023-06-30，75 个（2017-01-25 至 2023-06-20）；test 28 个，只在最终审计时评分一次。
- 计分目标集合每个 split 内固定（观测 ≥ 3）；bootstrap 是循环块抽样，每次抽样的目标组成相同。
  有观测的目标上候选 CRPS 非有限，判为违规。Q 样本限定 IV ∈ (0, 3]、|carry| < 2。
- 健全性检查：
  - 参考模型对自己的 skill 为 0；
  - 方差放大会显著降分，主要损失在波动率族；
  - 两个手写 fixture 在 dev 上的总分（固定窗口版本）：GARCH-t 为 −0.002（波动率族 +0.093，payoff 探针族
    +0.014，Q 侧 −0.101），过滤历史模拟为 −0.027。

## 不变量

- 预测函数拿不到日期、指数点位和起点之后的任何数据。日期仍可能被间接反推（Q 窗口内的上市时点、
  收益形态与预训练记忆），见 OpenHyra TASK.md 第 6 节。
- P 侧路径样本与 Q 侧报价样本分开评分，参考模型的 Q 侧不使用 P 侧参数。
- 面板位于 `data/derived/`，不是冻结证据；复现靠 `panel.json` 记录的来源与参数，加上本仓库代码。

## 接入 Stochopia：世界模型作为 P 侧生成器（2026-11-08）

OpenHyra 循环选出的 `r02s01`（DeepSeek V4.1 Flash，第 3 轮第 2 个候选）已冻结拷入本仓库，作为 Stochopia 的
P 侧情景生成器。这样，Stochopia 模拟出来的世界就是循环当前的认知；真实市场仍然是唯一的评分者。

| 文件 | 内容 |
|---|---|
| `stochopia/research/world_models/r02s01.py` | 原样拷贝的模型程序，文件头记录来源、分数与审阅结论 |
| `stochopia/research/world_models/__init__.py` | 注册表：每个模型的来源、分数，以及 SPEC 11.2 的层级（`tier`）与各层检验状态（`tier_checks`）。`ewma_gbm_reference` 也在其中 |
| `stochopia/research/world_model_generator.py` | `generate_scenario(panel, as_of, model, n_paths, horizon_days, seed, continuation_samples)`：从真实面板的某个交易日出发，生成联合日频路径与 Q 报价，以 21 天为一步拼接更长的期限；`dsl_paths()` 直接转成 StructurerDSL `Paths`，默认不折现 |

拼接规则：
- 模型调用一律用打分时的样本数 256。r02s01 在样本维度上标准化冲击，所以它的分布依赖请求的样本数。
  第一步从一次 256 样本调用里取前 n 条；之后每一步，每条路径单独调用一次 256 样本的预测，保留一条。
- `continuation_samples` 可以调小来提速（演示的校准用 32）。代价是续跑分布的尾部略薄：实测 21 天收益的
  标准差低约 2%，峰度 3.8 对 4.1。
- 每一步结束后，每条路径用自己模拟出的收益滚动收益窗口；`rate_3m` 保持不变（r02s01 和参考模型都不读它）。
- Q 窗口里已有至少 15 个报价时，才从最近一个报价无噪声线性插值到本步的样本值（IV 在对数空间插值）；
  否则保持 NaN，模型的默认报价不会被写进历史。as-of 窗口报价不足的 Q 序列，在 `manifest["q_supported"]`
  里标为 false，它们的 `q` 样本是模型默认值，不是由数据驱动的。
- 已知偏差：无噪声的插值段会让 r02s01 在第 2、3 步估计的 Q 离散度偏低（第 3 步 AR(1) 残差标准差约低 25%）。
  P 侧路径不受影响，因为 r02s01 的收益部分不读 Q 窗口。
- seed 由 as-of 日期派生，不依赖面板下标。各条路径可交换，但不独立：每次模型调用都会固定样本间的冲击均值。

测试覆盖：
- 把面板截断到 as-of 当天后重新生成，结果逐位相同，说明没有用到 as-of 之后的数据；
- 本仓库内运行拷贝的模型，复现循环里的 dev / test 分数（+0.0478 / +0.0783）；
- 同一 seed 结果确定，不同 seed 结果不同；面板起点平移后，同一日期得到同样的路径；
- 报价不足时不写入历史，并在 manifest 中标出。

**层级状态**（StructurerDSL SPEC 11.2，2026-11-10 起按层级命名）：r02s01 目前在**草稿层**。
- 自洽层：检验尚未实现。已知两处按现状过不了：它的分布依赖请求的样本数；一次调用内各条路径可交换但
  不独立（见上面的拼接规则）。生成器固定用 256 样本调用它，只是绕开了第一处，不算通过。
- 预测层：没跑。它在 dev 和 test 上的 CRPS skill 下界都大于 0，但这与预测层的判据（相对单一 GBM 的预测
  log score 加风格化事实检验，以及与 bootstrap、GARCH-t 的对照）不同。
- 决策层：没跑（历史与合成情景上的策略排序一致性）。

因此注册表把它标为 `development_only`，在它的路径上得到的占优结论**不能作为声明证据**。

### 演示：3 个月 CSI1000 雪球（KO 1.03，第 1、2 个月末观察；KI 0.85，按日观察；票息 15%）

运行 `.venv/bin/python -m stochopia.research.world_model_generator`，约 80 秒。

2025-12-31 出发，8 个 seed、每个 seed 256 条路径，完整保真续跑，报告均值 ± seed 间标准差。
单个 seed 的估计不稳定：r02s01 的敲入概率单次可以落在 5.5%–10.6%。

| 世界 | 敲出概率 | 敲入概率 | 期望 payoff |
|---|---:|---:|---:|
| EWMA-GBM 参考 | 39.2% ± 3.6% | 3.3% ± 0.8% | 1.0231 |
| r02s01 | 43.9% ± 1.3% | 8.5% ± 2.1% | 1.0124 |

在 r02s01 的世界里，这只雪球的敲入风险大约是 GBM 世界的 2.6 倍，期望 payoff 低约 1.1 个百分点。
用这两个世界做设计，会得到明显不同的结论。至于哪个更接近真实，见下面的校准。

逐期前推的校准：
- 每个起点按两个世界给出敲出 / 敲入概率（每个起点 1 个 seed，续跑样本 32），与真实发生的情况比较，计算 Brier 分数。
- 这里的"敲入"指 63 天内任何时刻触及 0.85，敲出之后的触及也算，所以不完全等于雪球实际生效的敲入。
- 起点间隔 21 天，结果窗口 63 天，相邻窗口重叠，test 的有效样本约 9。
- 差值的 90% 区间用循环块 bootstrap（块长 3，2000 次）。

| split | 起点 | 实际敲出 / 敲入 | 敲出 Brier：GBM / r02s01（差值，90% 区间） | 敲入 Brier：GBM / r02s01（差值，90% 区间） |
|---|---:|---|---|---|
| dev | 75 | 37.3% / 18.7% | 0.2403 / 0.2365（−0.004，[−0.015, 0.007]） | 0.1708 / 0.1669（−0.004，[−0.012, 0.004]） |
| test | 26 | 50.0% / 23.1% | 0.2520 / 0.2347（−0.017，[−0.033, −0.003]） | 0.2080 / 0.2012（−0.007，[−0.029, 0.014]） |

结论：
- 在 dev 上，r02s01 与 GBM 的差异无法与零区分。
- 只有 test 上的敲出差值区间不含 0。但 test 有效样本只有约 9 个，每个起点只用 1 个 seed，而且这段时期已被
  本项目用过，所以只能算弱证据。
- 两个模型都低估了真实敲入频率：dev 平均预测 12.2% / 14.3%，实际 18.7%；test 平均预测 17.0% / 18.5%，实际 23.1%。
- r02s01 的优势主要在波动率预测上，还没有可靠地传导到路径依赖结构的风险上，这与 21 天 payoff 探针族提升很小
  一致。这个判断只依据 dev 结果。test 已经看过一次，下一轮循环不应再根据 test 结果调整方向。
- dev 最后几个起点的 63 天结果窗口延伸到 2023-07 至 2023-09，越过了 `DEV_END`。它们只用于这里的诊断，
  不参与循环反馈。

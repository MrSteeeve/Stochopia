# P1-M4 深市 Level-2 开放算子演化实验

本研究在两只深市股票上比较五个实验臂。每只股票使用 36 日训练、12 日开发和 12 日独立复验。各臂登记三个搜索种子，每个种子演化三轮。开发侧共 90 次候选试验。实验代码锁定在 Stochopia `400443b5039ea1b073bbc9a1156cac079ad15e3f` 和 OpenHyra `66533dae928e0a64eda8232147c92fda4326e32e`。

## 实验结果摘要

开发期 90/90 次落盘，零次晋升。留出集 30/30 项均有终态，20 项完成配对测量，10 项评估失败。19 项首轮候选中 15 项得到有限的 LOB-Impact，冻结最终选中模型在五臂均为种子。

| 股票 | 冻结最终模型（五臂） | 留出 LOB-Impact [95%] | NLL（nats/事件） |
| --- | --- | ---: | ---: |
| 000001.SZ | `seed-gru` | 43.01 [29.94, 76.93] | 7.7558 |
| 300001.SZ | `seed-gru` | 37.66 [23.13, 61.72] | 8.3373 |

首轮候选的留出终态为 `GUARDRAIL_VIOLATION` 1 项、`REFUTED` 14 项、`evaluation_failed` 4 项。0 项通过性能涨分门槛。开发期的 `UNVERIFIED_GAIN` 审计集为 0 项。六个跨股辅助方向中 1 项完成测量，1 项得到有限的 LOB-Impact。

## 测量协议

`stochopia-p1-m4-v1` 在完成 40/90 次开发试验后因协议字段与指标极性歧义中止。累计 42 次 API 请求、74,560 个输入 token 和 26,650 个输出 token。留出集始终封存。工具链修复并完成冒烟核验后，独立登记 `stochopia-p1-m4-v2`，V1 账本留作预演诊断。

三层验证器先检查候选张量契约及前缀因果，再核验验证 NLL 与自由盘口存续。最后要求 LOB-Impact 净涨分至少 0.50 且配对重抽的单侧 5% 下界大于零。LLM 候选还须有主预测获支持、护栏预测未被推翻。随机变异组使用相同的契约及性能门槛，并登记固定预测占位。评分按交易日配对重抽 2,000 次。完整面板先判定 C2 是否可识别。对可评分模型，区间条件于该判定，每次重抽重新聚合物理读数并计算综合分。至少 6 个共同有效日及 1,800 次有效配对重抽时，在有效的配对重抽上报告区间与单侧下界，同时报告原始支持集和未定义次数。

本研究采用外生子单注入、盲组与回落读数，并沿用候选选择冻结后再开启留出集的审计原则。 [LOB-Impact](https://arxiv.org/html/2610.27100v1) · [留出集审计](https://arxiv.org/html/2610.14063v1)

### 冒烟与锁码

原 API 冒烟有两组通过（`evidence_ds`、`metrics_gpt`），9 次请求共 14,145 个 token。仅补测 `evidence_gpt` 和 `metrics_ds`，4 次请求共 6,626 个 token，低于另行授权的 10,000 个 token。补测沿用已编译的种子定义与合法接口说明，两组首次编译即通过。两个 metrics 组均事前预测 LOB-Impact 提高。原回执与前两组结果保持原样。`no_llm` 在 000001.SZ 的搜索种子 17 完成 24 个配对窗口 × 3 个训练种子。V2 正式演化前四组均通过 API 契约门槛。完成并校验 90 次开发记录和冻结源码后，才首次读取后 12 个交易日。两批通过回执见证据包的 `smoke_gate.json`。

### 开发覆盖与终态

90 次均有终态。33 次提案未生成，8 次未取得可执行程序（含 2 次代码调用传输失败），25 次评估失败，21 次判为 `REFUTED`，3 次违反回放耗尽窗口护栏。49 个候选通过编译，24 个完成配对测量，20 个得到有限的 LOB-Impact 分数。9 个分数点估计上升，7 个至少上升 0.50 分。七者的单侧重抽 5% 下界均未超过零。因此开发期没有已证实晋升，也没有通过性能要求后仅因预测未获支持而被拦截的 `UNVERIFIED_GAIN`。

开发基线为 000001.SZ 34.4069、300001.SZ 27.4745。冻结的 30 条轨迹均保留自己的种子。开发候选的最大分数点增量为 +4.7203（000001.SZ 的 `metrics_gpt` 种子 29 第 3 轮），单侧 5% 下界为 −6.3128。下界最接近零的候选增量为 +4.6175（000001.SZ 的 `evidence_gpt` 种子 41 第 1 轮），下界为 −0.0958。

239 次 API 传输尝试中，94 次收到响应并返回计量，共 199,950 个输入 token 和 83,874 个输出 token。145 次以传输错误结束，服务端用量未知。传输错误均集中于 300001.SZ，其中 137 次发生在提案调用，8 次发生在代码生成。该股票的 LLM 组未产生完成配对测量的开发候选。两股票之间可比较的 LLM 候选覆盖不均，无法用该结果估计证据注入或供应商的相对效果。

25 次评估失败包括 22 次拟合超时、1 次评估超时和 2 次运行异常。两次运行异常分别为实际训练权重违反状态一致性检查，以及复用已训练权重后仍未完成评估。两次均通过已锁码的评估失败路径登记实际错误，再续跑既定队列，没有为它们填入分数。

### 复验执行记录

留出数据首次获取遇到上游网关超时。续传复用已成功下载的投影，随后对既定 12 天完成对账。300001.SZ 共用种子的首个回放进程退出，第三个训练种子停在第 18/24 个窗口，未形成有效读数。恢复时仅该共用任务的回放进程上限由 600 秒延至 1,200 秒。沿用冻结任务、训练权重和回放随机种子，完成后写入原复验账本。其余已完成的任务由任务 ID 复用，候选按默认评估时限执行。该恢复由运行异常触发，早于该任务任何指标输出。

300001.SZ 的首轮 `evidence_gpt` 候选也在第三个训练种子的第 18/24 个窗口后退出。复验器将这个已有失败登记为终态。其余 9 项失败均有到达 CPU 时限的系统退出码，沿用原有评估失败路径写入账本。10 项失败都以 300001.SZ 为目标股票，响应与置信区间保留为空。

## 辅助架构与结果解释

### 六个辅助架构

主矩阵五个实验臂的开发选择均保留了 `seed-gru`。同一目标股票上的主矩阵单元共享种子结果。辅助矩阵有五个从 000001.SZ 生成的候选和一个从 300001.SZ 生成的候选。跨股时将候选源码传到目标股票，从目标股票训练数据独立拟合。异地评估以目标股票的种子为父对照。开发侧针对原股票作出的预测保留其原适用范围。

| 来源股票 | 实验臂与试验 | 源码中的实际改动 |
| --- | --- | --- |
| 000001.SZ | `evidence_gpt`，种子 41 第 1 轮 | 48 维 GRU 状态外加 4 条历史撤单方向的指数轨迹（半衰期 4、16、64、256 事件），零初始化的线性投影加到 GRU 输入投影，再经 tanh，累积状态合计 52 维。 |
| 000001.SZ | `metrics_gpt`，种子 29 第 3 轮 | 从当前一档、三档盘口不平衡和总深度提取四个量，零初始化投影加到 GRU 读出，GRU 的循环状态仍为 48 维。 |
| 000001.SZ | `evidence_ds`，种子 17 第 3 轮 | 声明一条方向分支，但逐步更新、批量前向和预测头均未调用它。与种子共享实质计算路径，用于核对名义改动与可执行改动的区别。 |
| 000001.SZ | `metrics_ds`，种子 29 第 1 轮 | 当前深度比、价差和不平衡的交互特征驱动一个门控的 48 维 GRU 输入残差，残差零初始化，未增加循环状态。 |
| 000001.SZ | `no_llm`，种子 29 第 1 轮 | 用 36+36 维快慢双对角递归替换 GRU。快支接收原输入，慢支接收双边对数总深度，合并到 72 维读出。 |
| 300001.SZ | `no_llm`，种子 29 第 3 轮 | 用 48 维实数对角 LRU 替换 GRU，输入乘以 `sqrt(1 − d²)`，状态按每通道衰减 `d` 更新。 |

模型中的滞后与半衰期按事件数定义，两股事件到达率不同时对应不同的物理时间。辅助行来自开发集的事前冻结候选目录，可检验同一实现的迁移表现。两只股票构成这次实验的市场范围。

### 首轮候选与机制预测

000001.SZ 的 15 个首轮任务均完成测量。成对分数点增量最大的是 `evidence_ds` 种子 41 的首轮候选，得分 51.28，对同条件父模为 +8.27 分。单侧重抽 5% 下界为 −1.52 分，主预测不可判定。300001.SZ 的四个首轮候选均以评估失败结束，缺少对应的配对分数。

LLM 的 13 个登记首轮主预测中，0 个获支持，2 个被推翻，11 个不可判定。三个无 LLM 搜索种子各自填有固定预测占位，其命中率没有与 LLM 预测合并。研究结论受两只股票的候选测量覆盖和日间波动约束。

### 跨股结果

从 000001.SZ 转到 300001.SZ 的五个辅助方向都在候选回放触及 CPU 时限后结束。唯一完成测量的跨股辅助方向是把 300001.SZ 的无 LLM 对角 LRU 放到 000001.SZ 重训。成对 LOB-Impact 点差为 −5.41 分，95% 区间 [−27.13, 19.30]。逐日配对 NLL 下降 0.0129 nats/事件，95% 区间 [−0.0265, −0.0020]。两项读数分别反映下一事件预测和注单后盘口响应，冲击分数的变化方向仍不可判定。五个失败单元限制了跨股架构迁移的判断。

本次实验的冲击成绩衡量固定注单协议下的模拟盘口响应。12 个独立留出交易日用于初始化和校验真实盘口及背景统计，评估对象是模拟可见组、盲组和自由路径。

# P1 深市世界模型起点基线 $E_0$（M3 校准）

本轮用 `000001.SZ` 和 `300001.SZ` 的真实深市 Level-2 数据拟合离散五元组 GRU。开发侧比较同窗历史重放、无注单生成及买卖方向的可见和盲组注单。注单结果是模型和撮合器在深市初始盘口上的模拟响应，实盘因果冲击需要另有母单记录与识别设计。

## 主要结果

两只股票各完成 3 次拟合、24 个时段窗口，共计 144 个窗口与种子组合。四个分项 NLL 均非负，单位为 nats/事件。两股总 NLL 相对训练经验边缘下降，最大分项改善来自相对档位头。闭环仍暴露出两类失真。

- `000001.SZ` 子单增至 33,700 股，8 笔合计为训练期中位一档深度的 64.1%。可见组末笔冲击为 0.299 tick，95% 区间为 [0.212, 0.382]，C2 可识别规模指数。可见冲击为盲组的 1.21 倍，C3 未通过。每窗平均生成 492 笔事件，历史为 656 笔。LOB-Impact 得 34.4/100。
- `300001.SZ` 子单保持 700 股。可见组末笔冲击为 1.003 ticks，95% 区间为 [0.451, 1.663]。平均绝对末端漂移由历史的 4.60 升到 5.68 ticks。12 个开发日的回落轨迹齐全，停手末端冲击为执行末端的 1.70 倍。C5 因恢复斜率为正而未通过，LOB-Impact 得 27.5/100。

M3 同时更换了拟合协议和子单标尺。两轮基线的差异包含这两项变化，单项贡献需用固定另一项的对照测量。

## 数据边界

三表使用固定 Hugging Face 数据版本。交易日按时间顺序登记，春节前的 `20170125`、`20170126` 和节后首日 `20170203` 排除在外。训练和开发之间、开发和测试之间各留一日隔离。测试侧只登记日期。逐笔和盘口缓存、权重、完整路径和机器可读残差存放于库外 `MarketData/Stochopia-SZSE-P1/`。 [数据集](https://huggingface.co/datasets/venvoo/china-a-share-l2-level2-limit-order-book-tick-data) · [P1 契约](Stochopia-OpenHyra-P1-PRD-and-Contract.md)

真实数据预检发现，部分 `U` 本方最优委托的 Wind 价格列记录了价格上限或下限。对应成交记录显示其实际挂单价为到达前的本方最优价。按此规则重建全部训练和开发缓存，并在拟合前检查事件目标是否落入模型的合法桶。 [深交所交易系统 FAQ](https://www.szse.cn/www/marketServices/technicalservice/introduce/P020180328467244590967.pdf)

首次开发运行发现一个窗口带着交叉盘口开始，随即中止。逐笔记录显示一笔类型 `1` 委托的剩余量按即时成交价留在簿上，Wind 价格列记录的是占位限价。重构改用即时成交的最远价格，未见即时成交时取到达前的对手一档。按纠正后的规则重建缓存，再以双侧且价差为正的初始簿启动本报告的开发运行。

每股每日对同一正成交水位取首个快照。`000001.SZ` 的快照时刻减首次到达该水位的成交时刻，中位数为 1.00 秒（168,748 个水位），`300001.SZ` 为 4.09 秒（82,113 个水位）。后者的一档匹配率按水位对齐提高 3.74 个百分点，支持约三秒的相对时间差。延迟发生在哪一段链路仍待独立时钟证据。

## 实验协议

- 每股独立拟合三个种子 `103`、`137`、`211`。在 36 日早晚盘中抽取同一交易场次内连续 256 个事件，前 64 个事件用于预热隐状态，从第 65 个事件起计算四头交叉熵。批量 16，AdamW 训练 1,200 步，权重衰减 `1e-4`，余弦学习率从 `2e-3` 降至 `1e-4`，梯度范数上限 1。单种子训练预算为 60 秒。候选上限为 28,000 参数和 128 个实状态标量。GRU 实测为 21,932 参数和 48 个实状态标量。训练样本的自身标记均为 0，该特征的权重从 0 起始。
- 每个开发日从早晚盘各取一个固定窗口，选择不早于该盘中点的首笔可用事件。窗口前 128 笔真实事件仅用于预热，起点十档聚合量按每档一笔初始挂单装入 JAX-LOB。验证似然在同一物理窗口内按事件汇总，以加 0.5 平滑的训练集四个经验边缘分布为基线。似然是离散桶的交叉熵，单位为 nats/事件。
- 每窗使用同一盘口和随机种子，执行无注单、买卖可见、买卖盲组。每边安排 8 笔 IOC 子单，未成交余量立即取消。单笔大小取训练期主动单中位股数与训练期中位一档深度的 8% 两者中的较大值，后一项四舍五入到 100 股。子单频率为训练期主动单笔频的 10%。停手后再观察一个执行时长。盲组逐条重用无注单路径的绝对价格、数量和时间。可见组把自身子单及更新后的盘口送回生成器，并从子单时间起以同一背景随机抽样重新计算等待时间。历史窗口含选作起点的真实事件，生成从该盘口开始抽取第一笔事件的等待时间。
- 无注单及历史轨迹在同一物理网格取样，网格间隔为子单间隔的四分之一。历史网格用下一条保留事件的事件前盘口近似，M1 已过滤的空盘和单边时段无法由此恢复。主动方向自相关取前 8 个主动单滞后，有至少三个正值时做对数斜率拟合。Hurst 由网格滞后 `1, 2, 4, 8` 的均方价格增量斜率除以二得到。一档深度按买卖两侧的可用股数平均。两侧齐全时才读中间价和价差，生成侧覆盖率单列。
- 买卖冲击取同窗中间价位移之差的一半。精确子单读数在子单完成后、同刻背景消息前提取。三个种子与早晚盘先在交易日内等权平均，置信区间按可用开发日重抽。指数拟合的自变量是计划累计子单数，$Y$ 用实际成交股数占训练期日均成交股数的平方根和训练期日价格变动标准差归一化。峰值比要求同日可见及盲组均有读数，停手末点相对最后子单冲击的 $r$ 要求同日恢复轨迹完备。C2 的近零带为 ±0.5 tick。C5 通过需要同执行条件下校准的 OW 参考，本次斜率和漂移仍按原规则判定。0–100 分使用现有 LOB-Impact 评分函数，表示到文献目标区间的距离。 [评分设计](LOB-Impact-Scoring-Design.md)

复算入口为 `.venv/bin/python -m experiments.p1_m2_baseline --root /Users/williamqian/MarketData/Stochopia-SZSE-P1`，输出目录为库外 `baseline-m3/`。
